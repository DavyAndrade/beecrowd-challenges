# Beecrowd Dart Solutions

## Português

Repositório destinado a armazenar soluções para desafios do Beecrowd utilizando a linguagem Dart. Cada pasta contém o código-fonte e uma breve descrição do problema resolvido.

## English

Repository intended to store solutions for Beecrowd challenges using the Dart language. Each folder contains the source code and a brief description of the solved problem.
