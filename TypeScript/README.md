# Beecrowd TypeScript Solutions

## Português

Repositório destinado a armazenar soluções para desafios do Beecrowd utilizando a linguagem TypeScript. Cada pasta contém o código-fonte e uma breve descrição do problema resolvido.

### Como Executar

1. Certifique-se de ter o Node.js/Bun/Deno instalado em sua máquina.
2. Navegue até o diretório do desafio desejado.
3. Execute algum dos seguintes comandos para executar o arquivo TypeScript:

```bash
# Com Node.js
node challenge_code.ts

# Com Bun
bun challenge_code.ts

# Com Deno
deno run challenge_code.ts
```
